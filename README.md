# Калькулятор калорийности блюда

Адаптивное веб-приложение (PWA) для телефона и компьютера. Оно считает калорийность и БЖУ готового блюда с учётом уварки.

Сайт: https://kuzia84.github.io/kalkulyator-kaloriynosti/

## Что умеет

- Таблица ингредиентов: название с подсказками, вес, ккал, белки, жиры, углеводы. Расчёт идёт сразу при вводе.
- Строки «Итого», «На 100 г блюда» и «На 100 г готового блюда (с учётом уварки)» с полем веса готового блюда.
- Справочник продуктов на устройстве: стартовый набор по таблицам Скурихина, ранги популярности, новые продукты после первого использования.
- Поиск в Open Food Facts и USDA FoodData Central, если есть интернет. Без интернета — только справочник.
- Поиск по штрихкоду: фото, камера или цифры кода. Распознавание идёт на устройстве.
- Страница модерации справочника: поиск, сортировка, фильтры, правка, удаление с отменой, объединение дубликатов.
- «Мои рецепты», расчёт порции, диаграмма БЖУ, экспорт CSV, печать, перенос данных файлом JSON, светлая и тёмная тема.
- Работа без интернета и установка на телефон и компьютер.

## Запуск

Нужен Node.js 22.

```bash
npm ci --maxsockets 4 --no-audit --no-fund
npm run dev          # http://localhost:5173
```

## Тесты и проверки

## Сборка и развёртывание

```bash
npm run build        # папка dist
npm run preview      # проверка сборки на http://localhost:4173
```

Сборка для подпапки задаётся переменной `BASE_PATH`, например `BASE_PATH=/kalkulyator-kaloriynosti/ npm run build`.

Каждый пуш в `main` публикует сайт на GitHub Pages: workflow `.github/workflows/deploy.yml`. Камера на iPhone работает только по HTTPS, GitHub Pages его даёт.

## Ключ USDA

Поиск в USDA FoodData Central требует бесплатный ключ: https://fdc.nal.usda.gov/api-key-signup.

1. Откройте «Настройки».
2. Вставьте ключ в поле «Ключ USDA API».
3. Нажмите «Сохранить».

Ключ хранится только в IndexedDB этого браузера. Он не попадает в код, в репозиторий и в файл переноса данных.

## Допущения и риски

- **Стартовый набор.** У таблиц Скурихина нет API и открытой машиночитаемой версии. Значения 54 продуктов взяты из справочника «Химический состав российских пищевых продуктов» (Скурихин И. М., Тутельян В. А., 2002). Каждая запись проходит проверку `Б×4 + Ж×9 + У×4` с отклонением не больше 15 %. Записи получают признак «не проверено»: модератору стоит сверить их с печатным изданием и отметить.
- **Строка без продукта.** Вес строки, где продукт не выбран, не входит в «Итого». Иначе «на 100 г» занижалось бы весом без калорий.
- **Подозрительная калорийность.** Запись подозрительна, если отклонение от формулы больше 15 % и больше 5 ккал. Порог в 5 ккал убирает ложные срабатывания у малокалорийных продуктов (чай, зелень).
- **Open Food Facts.** Новый поиск `search.openfoodfacts.org` не отдаёт заголовок CORS, поэтому приложение использует `world.openfoodfacts.org/cgi/search.pl`. Этот сервис временами отвечает 503 без заголовка CORS (проверено 11.11.2026). Тогда браузер блокирует ответ, а приложение показывает подсказки справочника и пояснение «Не ответил: Open Food Facts». Лимиты OFF — 10 запросов поиска и 15 запросов продукта в минуту с IP. Данные под ODbL. Браузер не даёт задать свой `User-Agent`.
- **USDA.** 1000 запросов в час с ключа, приложение берёт не больше 16 в минуту. Названия на английском. Данные — CC0.
- **`BarcodeDetector`** нет в Safari на iPhone и в Firefox, там работает ZXing. ZXing распознаёт хуже на смазанных фото. Тогда приложение просит переснять или ввести цифры.
- **Камера** требует HTTPS и разрешение пользователя. Без разрешения работает загрузка фото.
- **Safari на iPhone** может удалить данные сайта, который не открывали 7 дней, если сайт не установлен на главный экран. Установите приложение или сохраняйте файл переноса данных.
- **Хранение.** Данные живут в одном браузере. Перенос между устройствами — файлом JSON, синхронизации с сервером в первой версии нет.
