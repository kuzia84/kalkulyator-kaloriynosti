# Контрольные примеры

Все примеры проверяют модульные тесты (`src/calc/calc.test.ts`, `src/dish/csv.ts` в `src/storage/recipes.test.ts`) и сквозные тесты (`e2e/main.spec.ts`).

| Входные данные                             | Ожидаемый результат                             | Формула                             |
| ------------------------------------------ | ----------------------------------------------- | ----------------------------------- |
| А: 200 г, 150 ккал/100 г                   | 300 ккал                                        | `150 × 200 / 100`                   |
| Б: 300 г, 200 ккал/100 г                   | 600 ккал                                        | `200 × 300 / 100`                   |
| А + Б                                      | 500 г, 900 ккал                                 | `200 + 300`, `300 + 600`            |
| А + Б, на 100 г блюда                      | 180 ккал                                        | `900 / 500 × 100`                   |
| А + Б, вес готового блюда 400 г            | 225 ккал на 100 г                               | `900 / 400 × 100`                   |
| Вес итого 0                                | «—»                                             | деление на ноль не выполняется      |
| Вес готового блюда пуст, 0 или не число    | «—»                                             | деление на ноль не выполняется      |
| Вес «12,5», сахар 399 ккал/100 г           | 50 ккал                                         | `399 × 12,5 / 100 = 49,875 → 50`    |
| Вес «12.5»                                 | то же, что «12,5»                               | точка и запятая равны               |
| 25 ккал/100 г × 58 г                       | 15 ккал                                         | `14,5 → 15` (0,5 — вверх)           |
| 0,7 г белка/100 г × 150 г                  | 1,1 г                                           | `1,05 → 1,1`                        |
| 3 строки по 0,4 ккал                       | итого 1 ккал                                    | сумма `1,2` округляется один раз    |
| Гречка 308 ккал, 200 г, вес готового 560 г | 110 ккал на 100 г готового, пояснение о приваре | `616 / 560 × 100`                   |
| Вода 0/0/0/0                               | не подозрительна                                | формула даёт 0                      |
| 200 ккал при Б 10, Ж 10, У 10              | подозрительна                                   | `(200 − 170) / 170 = 17,6 % > 15 %` |
| 1 ккал при Б 0,1                           | не подозрительна                                | разница 0,6 ккал меньше 5 ккал      |
| Порция 50 г, блюдо 200 г, 399 ккал         | 100 ккал                                        | `399 × 50 / 200 = 99,75 → 100`      |
| EAN-13 4601916007082                       | код верен                                       | контрольная цифра 2                 |
| UPC-E 04252614                             | UPC-A 042100005264                              | развёртка по правилам GS1           |
